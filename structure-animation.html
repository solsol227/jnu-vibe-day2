용어 사전

    

      
API : 프로그램끼리 대화하는 "주문 창구". 주소(/places)마다 하는 일이 달라요.

      
요청 / 응답 : 요청 = "목록 주세요", 응답 = "여기 있어요". 항상 이 한 쌍으로 움직여요.

      
JSON : 데이터를 담는 약속된 글자 포맷. 택배 상자 규격이라고 생각하세요.

      
CORS : 서버의 출입 명단. 허락된 사이트(FRONT_ORIGINS)만 서버를 쓸 수 있어요.

      
.env / 환경변수 : 비밀번호·열쇠를 코드 밖에 따로 적어 둔 메모. 깃에 올리면 안 돼요.

      
포트(8000) : 한 컴퓨터 안의 "문 번호". 127.0.0.1은 "내 컴퓨터"라는 뜻이에요.
